Date: 09/11/2026

Offensive Security Intro
Offensive security = hacking systems legally to find weaknesses before criminals do.
Used dirb to find a hidden page on a practice bank website, then used it to move money.

Lesson: a hidden page isn't a secure page. It needs proper access control.

Defensive Security Intro
Defensive security = preventing, detecting and responding to attacks.
Learned about SOC, threat intelligence, incident response and malware analysis.
Used a practice SIEM to find a malicious IP address, escalate it and block it.


Careers in Cyber
Roles: Security Analyst, Engineer, Incident Responder, Forensics, Malware Analyst, Pentester, Red Teamer.
